# AI Developer Platform

A real, build-in-public AI developer tool — built one episode at a time on
[Fun with Learning Technology](https://www.youtube.com/@timepasshub2539) in
the **Building My Own AI Developer Platform** series.

Every episode is a genuine work session, not a scripted demo: the code, the
bugs, and the decisions here are what actually happened that day, and this
repo updates the same day the episode does. Nothing is rebuilt or cleaned up
for the camera afterward.

Follow along if you want to see what actually goes into building real AI
tooling — agents, MCP, RAG, memory, multi-agent coordination, deployment,
and everything that breaks along the way.
